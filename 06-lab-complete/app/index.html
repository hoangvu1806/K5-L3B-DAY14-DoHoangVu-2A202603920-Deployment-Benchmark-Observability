CP1 · PART 1 · 12-FACTOR APP

Nhận diện anti-pattern & chuẩn hóa Production

Hoàn thành

So sánh trực tiếp bản develop/app.py ("chạy được trên laptop") với production/app.py tuân thủ nguyên tắc 12-Factor để loại bỏ các lỗi chết người trước khi đóng gói.

Anti-patterns ở bản develop

  • • Hardcode OPENAI_API_KEY & DATABASE_URL trong code
  • • Dùng print() in thẳng API key ra stdout
  • • Không có /health và /ready
  • • Cố định localhost:8000 và bật reload=True

Chuẩn hóa ở bản production

  • • Đọc cấu hình qua os.getenv + fail-fast validate()
  • • Ghi log dạng JSON cấu trúc, không rò rỉ secret
  • • Có liveness /health và readiness /ready
  • • Bind 0.0.0.0:$PORT + lifespan xử lý SIGTERM

CP3 · PART 4 · API SECURITY

Ba lớp bảo vệ: Xác thực, Giới hạn tốc độ & Khóa ngân sách

401 · 200 · 429 · 402

Khi API mở ra Internet, phải chặn đồng thời truy cập trái phép, spam request và nguy cơ "cháy ví" LLM. Thử nghiệm thực tế với X-API-Key, JWT POST /auth/token (student / 10 req/phút) và Cost Guard dùng Redis INCRBYFLOAT.

401

Thiếu hoặc sai X-API-Key bị từ chối ngay tại cửa.

200

Key / JWT hợp lệ được phục vụ (Request #1 → #10).

429

Request #11 vượt 10 req/phút, trả kèm Retry-After: 59.

402

Tổng chi phí chạm trần ngân sách ngày/tháng → dừng gọi LLM.
