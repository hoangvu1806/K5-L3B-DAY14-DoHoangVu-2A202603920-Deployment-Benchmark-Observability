CP1 · Part 1 · 12-Factor 5+ anti-patterns fixed

Tách biệt môi trường Dev & Production

Loại bỏ thói quen hardcode trên localhost và chuyển toàn bộ cấu hình, log, health probe, shutdown sang chuẩn 12-Factor.

Trước (develop)

  • Hardcode key & DB URL trong code
  • print() in thẳng API key ra log
  • Không có /health, /ready
  • Cố định localhost:8000, bật reload

Sau (production)

  • Đọc os.getenv + fail-fast validate
  • Structured JSON log sạch secret
  • Tách riêng liveness & readiness
  • Bind 0.0.0.0:$PORT + SIGTERM
